# Exploratory Data Analysis Framework

## 1. Univariate Analysis

Analyze individual variables using:

* Mean
* Median
* Standard deviation
* Minimum
* Maximum
* Quartiles
* Histograms
* Box plots
* Bar charts

## 2. Bivariate Analysis

Analyze relationships such as:

* Rainfall vs yield
* Temperature vs yield
* Soil properties vs yield
* Crop type vs yield
* Region vs yield

## 3. Multivariate Analysis

Use:

* Correlation matrix
* Heatmap
* Pair plots
* Group comparisons
* Feature interaction analysis

## 4. Temporal Analysis

Analyze:

* Yield trends over years
* Rainfall trends
* Temperature trends
* Seasonal variations
* Exceptional agricultural years

## 5. Geographic Analysis

Analyze:

* Yield by region
* Weather differences by region
* Regional agricultural patterns
* Geographic data coverage

## Key Questions

1. Which crops have the highest yield?
2. Which crops have the highest yield variability?
3. How does rainfall relate to yield?
4. Does temperature affect yield?
5. Which regions have higher productivity?
6. Are there significant seasonal patterns?
7. Are missing values concentrated in particular regions?
8. Are there extreme agricultural events?
9. Which variables are most strongly associated with yield?
10. Which features should be considered for ML modeling?

## Expected Outcome

EDA should identify important patterns, data-quality problems and potential predictive features before machine-learning models are developed.
