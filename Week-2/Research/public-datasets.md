# Public Agricultural Datasets

## 1. FAOSTAT

FAOSTAT provides agricultural and food-related statistics covering countries and territories around the world.

### Relevant Data

* Crop production
* Crop yield
* Harvested area
* Country
* Region
* Year

### Application

FAOSTAT can be used for crop-yield analysis, agricultural trend analysis and development of ML prediction datasets.

---

## 2. NASA POWER

NASA POWER provides meteorological and solar data useful for agricultural and agroclimatology applications.

### Relevant Variables

* Temperature
* Precipitation
* Solar radiation
* Humidity-related variables
* Weather indicators

### Application

Weather variables can be combined with crop-yield data to investigate the relationship between climate and agricultural productivity.

---

## 3. USDA NASS Quick Stats

USDA NASS Quick Stats provides agricultural statistics that can be queried by commodity, location and time period.

### Relevant Data

* Crop statistics
* Production
* Area
* Yield
* Agricultural commodities
* Geographic information

### Application

The dataset can be used for agricultural analysis and as an additional source for model development or validation.

---

## 4. Satellite / Remote Sensing Data

Satellite data can provide information about crop vegetation and field conditions.

### Potential Features

* NDVI
* Vegetation indicators
* Water-related indicators
* Crop health information

### Application

Remote sensing can support crop-health monitoring, yield prediction and precision agriculture.

---

## 5. Soil Data

Soil datasets can provide:

* Soil type
* pH
* Organic matter
* Nutrient information
* Soil texture

These variables can improve agricultural prediction models by representing field-level soil conditions.

---

## Dataset Selection Strategy

For the initial project, structured crop-yield and weather data will be prioritized because they are easier to clean, interpret and model.

Remote-sensing and soil datasets can be added during later stages.

## Data Quality Challenges

Common challenges include:

* Missing values
* Different units
* Different geographic scales
* Different temporal frequencies
* Duplicate observations
* Inconsistent category names
* Measurement errors
* Extreme values
* Revisions to historical statistics
* Limited local representation
