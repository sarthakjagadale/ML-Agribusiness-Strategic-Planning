# Agricultural ML Case Studies

## Microsoft and ICRISAT – Andhra Pradesh

An AI-enabled sowing advisory system used weather and agricultural information to provide sowing recommendations.

### Lesson

AI solutions can be useful even when delivered through simple communication channels such as SMS.

---

## AGRIST

AGRIST uses agricultural sensor and harvest information with machine learning for forecasting.

### Lesson

Production ML requires continuous data collection, monitoring and model updates.

---

## Key Lessons

1. Technology must address a real agricultural decision.
2. Local validation is important.
3. Farmer usability is critical.
4. Data quality strongly affects model performance.
5. ML systems require continuous monitoring.
