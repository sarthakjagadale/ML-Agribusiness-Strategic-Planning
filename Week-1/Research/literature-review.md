# Literature Review – Machine Learning in Agriculture

## Research Focus

The literature review focuses on the application of Machine Learning and Deep Learning for:

- Crop yield prediction
- Precision agriculture
- Crop disease detection
- Irrigation optimization
- Soil analysis
- Agricultural forecasting

## Key Findings

Research indicates that agricultural prediction systems commonly use:

- Temperature
- Rainfall
- Soil characteristics
- Vegetation indices
- Crop history
- Remote sensing data
- Weather information

Common ML algorithms include:

- Linear Regression
- Random Forest
- Gradient Boosting
- Support Vector Machine

Deep Learning approaches include:

- CNN
- LSTM
- Transfer Learning

## Research Conclusion

The literature indicates that combining multiple agricultural data sources with ML can provide better decision support than relying on a single data source.
